## القوالب المعتمدة

- رياضيات الأول الابتدائي: **3 نماذج**.
- علوم الثالث: القوالب المعتمدة داخل المشروع.
- علوم الرابع: **10 نماذج**.
- التربية الإسلامية: **10 نماذج** بتوزيع الدرجات `٢ + ٢ + ٢ + ١ + ١ + ١ + ١ = ١٠`.
- الأظرف: **9 نماذج** معتمدة.
- شهادات التقدير: **10 نماذج**.

العربية RTL، والأرقام التعليمية الافتراضية عربية `٠١٢٣٤٥٦٧٨٩`، والترويسات شبه تلقائية وقابلة للتعديل والحفظ التلقائي.

## الأمان وتسجيل الدخول

- الدخول الرئيسي مرتبط بـ Supabase Auth؛ كلمة المرور ليست ثابتة داخل المصدر ولا تحفظ في GitHub أو `localStorage`.
- دعم المصادقة الحيوية الأصلية بواسطة `expo-local-authentication`.
- تخزين الأسرار المحلية المسموح بها بواسطة `expo-secure-store`.
- وضع خصوصية يستخدم `expo-screen-capture` وفق دعم Android.
- حد أقصى **5 أجهزة** للحساب؛ أول جهاز رئيسي والبقية فرعية بصلاحيات قابلة للإدارة.
- الجهاز الرئيسي يدير إيقاف/تفعيل/حذف وإعادة تسمية الأجهزة الفرعية وتخصيص صلاحياتها.
- رمز مستقل للعمليات الحساسة ونقطة أمان محلية للطوارئ.
- حظر مؤقت تدريجي بعد تكرار محاولات الدخول الخاطئة.

## المرونة والحفظ

- الحفظ التلقائي إلزامي في النماذج والإعدادات والتعديلات.
- Pinch Zoom وأزرار +/−/100% في مساحات العمل المدعومة، مع وضع تحريك وحفظ مستوى التكبير.
- تكبير المعاينة لا يغيّر قياس الطباعة أو PDF.
- صياغة الأسئلة مستقلة عن صناعة الأظرف في التحرير والحفظ والطباعة.

## بناء المشروع

المتطلبات: Node 20، Java 17، Android SDK.

```bash
npm install --no-audit --no-fund
npm run check:web
npm run android:prebuild
cd android
./gradlew assembleRelease
```

`android:prebuild` ينشئ مشروع Android ثم ينسخ محتوى `web/` إلى أصول التطبيق.

## GitHub Actions وAPK

Workflow: `.github/workflows/android.yml`

عند كل Push إلى `main`:

1. تثبيت الاعتماديات.
2. تشغيل `npm run check:web`، ويشمل فحص المشروع والأمان.
3. Expo Android prebuild.
4. Gradle Release build.
5. رفع APK كـ GitHub Actions Artifact لمدة 14 يومًا.

اسم الـArtifact يبدأ بـ:

`abu-bassam-android-<commit-sha>`

إذا كانت أسرار مفتاح التوقيع موجودة، يبنى Release بالمفتاح المعتمد. لا يوجد keystore أو كلمة مرور توقيع داخل المستودع.
