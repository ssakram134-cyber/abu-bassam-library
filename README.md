# مكتبة أبو بسام — Android 4.3

المستودع الرسمي لتطبيق **مكتبة أبو بسام للتصوير والقرطاسية**.

- المصمم والمبرمج: **أكرم حاتم الغزالي**
- الحزمة: `com.abubassam.librarycamera3`
- الإصدار الحالي: `4.3.1`
- رقم البناء: `431`

## نطاق هذا المستودع

هذا المستودع لتطبيق مكتبة أبو بسام فقط. لا توضع فيه ملفات **مساعد المعلم** أو **Phone.Max** أو أي مشروع آخر.

يشمل المشروع: الصور الحكومية والطباعة، البطاقة الوطنية والمستمسكات، الباجات والكروت وباج المواكب، QR/Wi‑Fi، الحفظ والمستندات، صياغة الأسئلة العربية والإنكليزية، التصاميم الخمسة المعتمدة للأسئلة، وضغط الصور.

## استيراد المصدر الكامل أول مرة

موصل GitHub المستخدم من ChatGPT يكتب الملفات النصية مباشرة، لكنه لا يرفع ملف ZIP ثنائيًا من مساحة العمل. لذلك تم تجهيز Workflow آمن لاستيراد المصدر الكامل من ملف ZIP واحد.

1. ارفع الملف `Abu_Bassam_Library_v4.3.1_Latest_Source.zip` إلى جذر المستودع.
2. شغّل Action باسم **Import Abu Bassam source ZIP** من تبويب Actions، أو اترك تشغيله التلقائي عند رفع الملف.
3. يفحص الـWorkflow هوية التطبيق، يفك المصدر، يستبعد نواتج الاختبار المحلية، يشغّل `npm ci` و`npm run check:web`، ثم يكتب المصدر الحقيقي إلى `main`.
4. بعد نجاح الاستيراد سيحذف ملف ZIP من المستودع حتى يبقى المصدر مرتبًا وقابلًا للمراجعة.

## بناء Android

بعد استيراد المصدر الكامل، يقوم Workflow الخاص بـ Android بفحص المشروع وبناء APK تجريبي Debug تلقائيًا.

لإنشاء Release موقّع أضف أسرار GitHub التالية فقط:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

راجع `docs/GITHUB-SECRETS.md` للتفاصيل. لا تضع ملف التوقيع أو كلمات المرور داخل المصدر.

## قاعدة الاعتماد

لا تعتبر أي ميزة «تمت» لمجرد ذكرها في المحادثة. الاعتماد الحقيقي يكون بعد وجودها داخل المصدر ونجاح الفحص، ويجب أن تكون نتيجة التدقيق واضحة: **تم ✅ / ناقص ⚠️ / غير موجود ❌ / يحتاج تحقق 🔍**.
