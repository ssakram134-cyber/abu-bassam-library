## صياغة الأسئلة
- عربي RTL وإنجليزي LTR.
- قوالب المواد والقوالب العامة المتفق عليها.
- A4/A5 عمودي وأفقي، مقاس مخصص، ملم/سم.
- حفظ تلقائي وطباعة وPDF.
- **اللمس الأصلي فقط**: نظام المرونة/Pinch/Move المخصص القديم معطل ولا يُحمّل.
- صناعة الظرف وكتاب الشكر والتقدير **ليسا داخل هذا القسم**.

## الواجهة على الهاتف
- أزرار أنواع الكروت تتحول إلى عمودين على الشاشات الصغيرة.
- أدوات الصورة والمنزلقات موزعة لمنع التداخل.
- النصوص الطويلة تلتف داخل الأزرار بدل القص والتراكب.
- الضبط والسجل في الموضع التنفيذي الحالي: تقريبًا `top: 76px`، مساحة لمس `52×52px`، رمز `24px`.
- أزرار التحكم العائمة السفلية القديمة مخفية.

## الأمان وتسجيل الدخول
- الدخول الرئيسي مرتبط بـ Supabase Auth؛ كلمة المرور ليست ثابتة داخل المصدر ولا تحفظ في GitHub أو `localStorage`.
- دعم المصادقة الحيوية بواسطة `expo-local-authentication`.
- تخزين الأسرار المحلية المسموح بها بواسطة `expo-secure-store`.
- وضع خصوصية يستخدم `expo-screen-capture` وفق دعم Android.
- حد أقصى **5 أجهزة** للحساب وفق التنفيذ الحالي، مع إدارة وصلاحيات الأجهزة.
- رمز مستقل للعمليات الحساسة ونقطة أمان محلية للطوارئ.

## بناء المشروع
المتطلبات: Node 20، Java 17، Android SDK.

```bash
npm install --no-audit --no-fund
npm run check:web
npm run android:prebuild
cd android
./gradlew assembleRelease
```

`npm run check:web` يشغّل تدقيق المشروع، تدقيق الأمان، وتدقيق أحدث الميزات قبل البناء.

## GitHub Actions وAPK
Workflow: `.github/workflows/android.yml`.

عند Push إلى `main`:
1. تثبيت الاعتماديات.
2. تشغيل `npm run check:web`.
3. Expo Android prebuild ونسخ `web/` إلى أصول التطبيق.
4. بناء APK.
5. محاولة بناء النسخة الموقعة عند توفر أسرار التوقيع.
6. رفع APK كـ GitHub Actions Artifact.

لا يوجد keystore أو كلمة مرور توقيع داخل المستودع.

## الحفاظ على البيانات
الحزمة تبقى `com.abubassam.librarycamera3`. تحديث APK بالمفتاح الصحيح يفترض أن يحافظ على بيانات Android الخاصة بالتطبيق، لكن اختبار التحديث فوق نسخة مثبتة يبقى **يحتاج تحقق 🔍** على هاتف حقيقي.

## قاعدة التدقيق
كل بند يدقق بإحدى الحالات فقط:
- `تم ✅`
- `ناقص ⚠️`
- `غير موجود ❌`
- `يحتاج تحقق 🔍`

نجاح المصدر والفحوص الآلية لا يثبت وحده جودة اللمس أو الطباعة أو QR بعد الطباعة على الجهاز الحقيقي.
