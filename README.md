# مكتبة أبو بسام — Android 4.3.2

تطبيق عربي يعمل محليًا أولًا لمكتبة أبو بسام للتصوير والقرطاسية، مع الكاميرا والطباعة وإدارة المستندات والكروت وQR والمزامنة الاختيارية الآمنة.

## هوية الإصدار

- اسم التطبيق: **مكتبة أبو بسام**
- المصمم والمبرمج: **أكرم حاتم الغزالي**
- الهاتف: **07829667521**
- الحزمة: `com.abubassam.librarycamera3`
- الإصدار: `4.3.2`
- رقم البناء: `432`
- الحد الأدنى: Android 7 عند استعمال حزمة Expo الحالية

## الأقسام الرئيسية

1. الصور الحكومية وصور المعاملات والطباعة.
2. البطاقة الوطنية والمستمسكات وبطاقة السكن وأفراد العائلة.
3. الباركود والكروت: الباج التعريفي، باج الروضة/المدرسة، كارت تسجيل الدخول، Wi‑Fi، QR وBarcode.
4. الحفظ والمستندات: صور وPDF وWord وExcel ونصوص، بحث وفرز ومجلدات ومفضلة وOCR ونسخ احتياطي.
5. صياغة الأسئلة: نموذج عربي RTL ونموذج إنكليزي LTR، تحرير A4، صور وتواقيع ومسودات وطباعة وPDF.
6. ضغط الصور: ضغط محلي متعدد الصور مع مقارنة الحجم وحفظ نسخة جديدة دون تعديل الأصل.

يدعم الاستديو والكاميرا وقارئ الباركود، الوجه الأمامي والخلفي، CR80 بقياس `85.6 × 54 mm`، الطباعة المباشرة وA4، JPG/PNG/PDF، الخطوط العربية، الثيمات، سجل العمليات، والأجهزة المتصلة للقراءة فقط.

## بناء المشروع

المتطلبات: Node 20، Java 17، Android SDK، ثم:

```bash
npm ci
npm run check:web
npm run android:prebuild
cd android
./gradlew assembleDebug
```

يقوم `android:prebuild` بإنشاء مشروع Android القياسي ثم ينسخ محتوى `web/` إلى `android/app/src/main/assets/library/`. لا تعتمد الوظائف المحلية الأساسية على خادم خارجي.

## توقيع نسخة التحديث

لا يوجد مفتاح توقيع أو كلمة مرور داخل المستودع. يبني GitHub Actions نسخة Debug تلقائيًا، ويبني Release موقعة فقط عند إضافة الأسرار التالية:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

يجب استعمال مفتاح سلسلة الإصدارات السابقة نفسها حتى يثبت APK كتحديث ويحافظ Android على بيانات التطبيق.

## المزامنة والخصوصية

- التطبيق يعمل محليًا بلا تسجيل دخول.
- المزامنة اختيارية وتستخدم Supabase Auth الرسمي.
- جدول المزامنة يطبق RLS بواسطة `auth.uid()`.
- المستندات ترفع إلى حاوية خاصة، ومسار كل مستخدم معزول بسياسات Storage RLS.
- لا تُحفظ كلمة المرور ولا يوجد `service_role` أو مفتاح سري في العميل.
- Google Drive وGmail يعملان عبر شاشة مشاركة Android الرسمية وبموافقة المستخدم.
- Telegram وWhatsApp يفتحان شاشة التطبيق/المشاركة، ولا يحدث إرسال صامت.

توجد تغييرات قاعدة البيانات في `supabase/migrations/`.

## الحفاظ على البيانات

مفاتيح `localStorage` وقاعدة IndexedDB الحالية لم تتغير، لذلك تبقى إعدادات وصور ومستندات سلسلة الحزمة `com.abubassam.librarycamera3` عند تثبيت APK موقّع بالمفتاح نفسه. قبل أي استعادة شاملة ينشئ التطبيق نسخة أمان، ولا يحذف Cache ملفات المستخدم.

راجع [دليل هوية التحديث](docs/PACKAGE-IDENTITY.md) و[قائمة فحص الإصدار](docs/RELEASE-CHECKLIST.md) قبل النشر.

## ملاحظات واقعية

- كشف الإطار والقص الحاليان ينفذان محليًا بعد الالتقاط؛ المعاينة الحية تعرض إطار إرشاد ولا تستخدم OpenCV frame-by-frame بعد.
- OCR وإزالة الخلفية يحتاجان تنزيل محرك خارجي في أول استخدام وبعد موافقة المستخدم.
- يجب إجراء اختبار الطباعة والكاميرا والتحديث على هاتف Android حقيقي قبل اعتبار الإصدار نهائيًا للإنتاج.
