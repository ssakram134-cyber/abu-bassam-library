## صياغة الأسئلة
قسم مستقل عربي RTL / إنجليزي LTR، مع أنواع الأسئلة والقوالب الخاصة والعامة وA4/A5/مخصص والحفظ والطباعة وPDF. **الظرف والشكر والتقدير وشهادات التقدير ليست داخل هذا القسم.**

## بدء التشغيل واللمس
- splash له watchdog مستقل ولا يعتمد فقط على `window.load`.
- إطارات الأسئلة والضغط Lazy-load عند فتح القسم بدل تحميلها أثناء الإقلاع.
- المرونة العامة وgesture/pinch المخصصة القديمة معطلة.
- اللمس والتمرير الأصليان للأسئلة.
- أزرار التحكم السفلية القديمة مخفية.

## تسجيل الدخول
- اسم المستخدم وكلمة المرور LTR.
- عداد المحاولات يحسب فشل بيانات الاعتماد الحقيقي فقط.
- أخطاء الجهاز بعد نجاح المصادقة لا تُسجل ككلمة مرور خاطئة.
- SecureStore، البصمة وإدارة الأجهزة مفعلة وفق المصدر الحالي.

## البناء
المتطلبات: Node 20، Java 17، Android SDK.

```bash
npm install --no-audit --no-fund
npm run check:web
npm run android:prebuild
cd android
./gradlew assembleRelease
```

GitHub Actions يبني **Standalone Release APK** ويشترط وجود `assets/index.android.bundle` داخله ويتحقق من التوقيع قبل رفع artifact. لا يعتمد APK الموزع على Metro.

الـAPK والـZIP الناتجان **Artifacts** مؤقتة في GitHub Actions وليسا ملفات مضافة إلى شجرة المصدر.
