# PROJECT MASTER SPEC — مكتبة أبو بسام

آخر تحديث: 2026-09-21. هذا المستند مع `AGENTS.md` هو المرجع الحالي للمشروع، وأحدث قرار صريح للمستخدم يلغي أي نص أقدم متعارض.

## الهوية
- التطبيق: **مكتبة أبو بسام**.
- الاسم التجاري: **مكتبة أبو بسام للتصوير والقرطاسية**.
- المصمم/المبرمج: **أكرم حاتم الغزالي**.
- العربية RTL افتراضيًا، والإنجليزية LTR حيث يلزم.
- Version `4.3.2` / build `432` / Android package `com.abubassam.librarycamera3`.

## الأقسام الرئيسية الحالية
1. صوري والطباعة.
2. البطاقة الوطنية والمستمسكات.
3. **الباركود والكروت**.
4. الحفظ والمستندات.
5. **صياغة الأسئلة**.
6. ضغط الصور.
7. الإعدادات والأمان وسجل العمليات.

## الباركود والكروت — المكان المعتمد
يحتوي: الباج التعريفي، باج الروضة/المدرسة، بطاقة تسجيل الدخول/الإيميل، Wi‑Fi، QR وقارئه، البطاقة التموينية، كروت المواكب الحسينية، **صناعة الظرف**، **شهادات التقدير**، و**كتاب الشكر والتقدير**.

يوجد زر مركزي «🧩 النماذج» لعرض الفهرس الكامل، كما يوجد زر «🧩 النماذج» داخل كل قسم تصميم. فتح الزر من قسم معين يعرض نماذج ذلك القسم فقط. قارئ الباركود ليس قسم تصميم ولا يحتاج نماذج.

المرجع المركزي للنماذج: `web/card-template-library.js`، والواجهة: `web/card-templates-v2.html`.

- تسجيل الدخول/الإيميل: **10**.
- Wi‑Fi: **3**.
- QR: **4**.
- البطاقة التموينية: **1**.
- المواكب الحسينية: **10**.
- صناعة الظرف: **9**.

- كتاب الشكر والتقدير: **6**.

## البطاقة التموينية
- CR80 ‏85.6×54 مم، وجه وظهر.
- الحقول: اسم رب العائلة، رقم البطاقة التموينية، الملاحظة.
- QR يحتوي **رقم البطاقة فقط**.
- حفظ تلقائي، طباعة كارت/A4، PDF وصور الوجه والظهر.

## كروت المواكب
- CR80 وجه/ظهر.
- **10 تخطيطات حقيقية**.
- الاسم، المناسبة، المسؤول، الهاتف، العنوان/الموقع، الرمز، الملاحظة، الشعار/الصورة وQR قابلة للتعديل.
- حفظ تلقائي، طباعة وPDF.

## صناعة الظرف
- **داخل الباركود والكروت فقط** وفق القرار الحالي، وليس داخل صياغة الأسئلة.
- **9 نماذج حقيقية**.
- المقاسات: 225×115، DL، C6، #10، C5، C4، A5/A4 كغلاف/ورق، ومخصص.
- A4/A5 ليست أظرفًا قياسية ويجب بيان ذلك في الواجهة.
- اليوم والتاريخ اختياريان.
- تحريك، تغيير حجم، تدوير، قفل، طبقات، حذف، نسخ، نصوص، صور، قص/استبدال، تنسيق، تراجع/إعادة، صفحات، توقيع، دعاء/بسملة، حفظ، طباعة، PDF وصورة.

## شهادات التقدير
- **داخل الباركود والكروت**.
- 10 نماذج حقيقية.
- A4/A5 عمودي/أفقي ومخصص.
- تحرير عناصر ونصوص وصور، حفظ، طباعة، PDF وصورة.
- لا توجد مقاسات باسم iPhone أو iPhone 5.

## كتاب الشكر والتقدير
- **داخل الباركود والكروت**.
- 6 نماذج حقيقية: الإطار الملكي، الشريط الجانبي، الوسام المركزي، الترويسة الأكاديمية، اللوحة الهندسية، الرسمي المبسط.
- الحقول: الجهة المانحة، عنوان الكتاب، اسم المكرّم، الصفة، النص، السبب/الإنجاز، التاريخ، التوقيع.
- حفظ تلقائي، طباعة وPDF.

## صياغة الأسئلة
- قسم مستقل، ولا يحتوي صناعة الظرف أو الشكر والتقدير أو شهادات التقدير.
- عربي RTL وإنجليزي LTR.
- كل سؤال يملك نوعه المستقل: فراغات، بين أقواس، تعاريف، تعداد، نقاط، اختيار من متعدد، صح/خطأ، إجابة قصيرة.
- قوالب خاصة بالمادة وقوالب عامة.
- علوم الثالث والرابع والتربية الإسلامية وفق التوزيعات المعتمدة.
- A4/A5 عمودي/أفقي ومخصص، حفظ تلقائي، طباعة وPDF.
- اللمس والتمرير أصليان دون طبقة gesture/pinch مخصصة.

## واجهة الهاتف
- منع تداخل النصوص والأزرار.
- أنواع الكروت عمودان على الهاتف عند الحاجة.
- أدوات الصور والمنزلقات موزعة بمساحة لمس واضحة.
- النصوص الطويلة تلتف بدل القص.
- أزرار الضبط والسجل: تقريبًا `top:76px`، مساحة `52×52px`، رمز `24px`.
- أزرار التحكم العائمة السفلية القديمة مخفية.
- المرونة العامة القديمة معطلة ولا يُحمّل `global-flex-runtime.js`.

## بدء التشغيل
- شاشة الشعار يجب ألا تعتمد وحدها على حدث `window.load`.
- يوجد watchdog مستقل لإخفاء splash بعد جاهزية DOM مع مهلة احتياطية.
- إطارات صياغة الأسئلة وضغط الصور لا تُحمّل أثناء الإقلاع؛ تُحمّل فقط عند فتح القسم لتقليل احتمال تعليق شاشة البداية.

## تسجيل الدخول والأجهزة
- حقلا اسم المستخدم وكلمة المرور LTR مع تعطيل autocapitalize وspellcheck.
- عداد المحاولات لا ينقص إلا عند فشل بيانات الاعتماد الفعلي، ولا يحسب أخطاء ربط الجهاز بعد نجاح المصادقة ككلمة مرور خاطئة.
- SecureStore والبصمة وإدارة الأجهزة تبقى مفعلة.
- إعادة تثبيت التطبيق على الجهاز نفسه تسمح بمصالحة/إعادة ربط سر الجهاز بعد المصادقة بدل إنشاء تعارض دائم.
- لا مفاتيح خاصة أو service-role أو كلمات مرور داخل ملفات الويب.

## Android والبناء
- `npm run check:web` إلزامي قبل البناء.
- `npm run android:prebuild` ينسخ مجلد `web/` كاملًا إلى `android/app/src/main/assets/library`.
- APK الموزع يجب أن يكون **release-mode standalone** ويحتوي `assets/index.android.bundle` داخل APK.
- CI يتحقق من وجود الـbundle ومن توقيع APK بواسطة `apksigner` ويرفض مسار `assembleDebug` كملف توزيع.
- عند عدم توفر مفتاح الإصدار الخاص، نسخة الاختبار قد تكون Release موقعة بمفتاح التطوير، وليست نسخة نشر متجر نهائية.
- ملفات APK/ZIP الناتجة تبقى GitHub Actions Artifacts وليست ملفات محفوظة داخل شجرة المصدر.

## قاعدة التدقيق
الحالات الوحيدة:
- **تم ✅**: موجود في المصدر واجتاز الفحص المناسب.
- **ناقص ⚠️**: جزئي أو لا يطابق القرار كاملًا.
- **غير موجود ❌**: غير منفذ.
- **يحتاج تحقق 🔍**: يحتاج هاتف/كاميرا/طابعة/QR فعلي.

نجاح المصدر وCI لا يساوي نجاح الاختبار على الهاتف. بدء التشغيل، الشكل النهائي، الطباعة وقراءة QR بعد الطباعة تبقى بحاجة اختبار فعلي بعد كل APK جديد.
