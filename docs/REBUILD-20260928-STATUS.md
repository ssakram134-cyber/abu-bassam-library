موافقة المستخدم على استخدام المتصفح السحابي لـ GitHub فقط، لأن الإضافة الحالية تفتقد حذف
Artifacts وقراءة رسالة check-run. هذه الخطوة لا تتصل بحاسوب المستخدم.
بعد حذف مخرجات التنصيب وقراءة سبب منع Runner يمكن تحديد الإجراء الفعلي اللازم للبناء.
لا يجوز إعلان إنجاز إعادة البناء أو نجاح الاختبارات أو تقديم APK قديم باسم جديد.
