# تدقيق قسم الحفظ والمستندات — مكتبة أبو بسام

آخر فرع مراجعة: `feat/vault-originals-file-management-20261009` (أساسه PR #36).

## مزايا مؤكدة من قراءة الشيفرة

| الميزة | التنفيذ داخل المستودع | حدود التنفيذ |
|---|---|---|
| الأرشيف المحلي | IndexedDB `AbuBassamDocumentVaultV4/items` | سقف 1000 عنصر؛ حد النسخة الاحتياطية وحجم الملف تحدده قواعد المشروع |
| رفع الصور | `vImageInput` و`addFiles` | لا تعتمد خدمة الإنترنت للحفظ المحلي |
| Word / Excel / PDF / عروض / ملفات أخرى | `vFileInput` وتحديد النوع من امتداد الملف، وعرض/حفظ الصيغة الأصلية | لا يحتوي التطبيق محرر Office أو PDF كاملاً |
| فتح | الصور داخل العارض، PDF في iframe، TXT/CSV/JSON/XML/HTML كنص | يعرض Word/Excel رسالة لحفظ/مشاركة الملف وفتحه بتطبيق Office مناسب؛ دعم PDF iframe يعتمد WebView |
| تحرير الصور | المحرر الأساسي والمحرر المتقدم | ينتج المحرران PNG ويمكن الاختيار قبل حفظ النسخة |
| تحرير TXT/CSV/JSON/XML/HTML | محرر نصي محلي حتى 5 MB | يعتمد UTF-8؛ لا يعدل بنية Word/Excel/PDF |
| إعادة نسخة Word/Excel/PDF معدّلة | «نسخة معدلة» / «تحرير / نسخة معدلة» يختار الملف من الجهاز | سير العمل يدوي: تحرير خارجي، حفظ الملف على الجهاز، ثم اختيار النسخة المعدلة داخل الأرشيف |
| الاحتفاظ بالأصل | اختيار «1» يحفظ الملف السابق كعنصر مستقل وينتظر المزامنة | يحسب الأصل كعنصر جديد ضمن حد 1000؛ يحافظ على امتداد ومحتوى وMIME القديم |
| استبدال الملف | اختيار «2» يستبدل محتوى العنصر الحالي | لا يُنشئ تاريخ إصدارات كامل عند الاستبدال؛ استخدم خيار «1» أو النسخ الاحتياطية إذا أردت الرجوع |
| سلامة الحفظ | معاملة IndexedDB ذرّية تشمل الأصل والمعدل مع فحص `syncRevision` | يجب اختبار قطع الكهرباء/نفاد السعة على Android فعليًا |
| البحث | الاسم، الامتداد، MIME، المجلد، تاريخ الإنشاء والتعديل كما يظهر بالعربية | لا يبحث داخل محتوى ملفات Word/PDF أو OCR تلقائيًا |
| الفرز | تاريخ الإنشاء، آخر تعديل، آخر فتح، الاسم، الحجم، النوع | آخر فتح يختلف عن تاريخ تعديل الملف |
| العرض | مصغرات، صور كبيرة، تفاصيل، قائمة | يتغير عرض المصغرات تبعًا لحجم الشاشة |
| التنظيم | مجلدات، مفضلة، فلاتر صور/PDF/Word/Excel/عروض/نصوص، مزامنة | الحذف المتزامن يتطلب صلاحيات مستخدم/فرع صالحة |

## اختبارات هذه المرحلة
- `tools/check_vault_file_management.js`: فلاتر Word/Excel، البحث بالتواريخ، وضعيات العرض، حفظ الأصل، الاستبدال، إلغاء العملية، رفض الكتابة فوق نسخة قديمة، والتحقق من MIME.
- تحديث `tools/check_document_vault_advanced.js`: حفظ الصور المتقدم يمر عبر المسار الذرّي المشترك.
- تحديث `tools/check_vault_offline_atomic_sync.js`: يستخدم اعتماد `fileMime` الجديد عند محاكاة رفع الدفعات.
- تم تشغيل اختبارات فرع الأرشيف وحفظ/استعادة النسخ القائمة في بيئة V8 مع محاكاة جزئية لـ Node. **هذا ليس اختبارًا على هاتف Android أو تشغيلًا كاملاً لـ npm.**
- تم تسجيل 50 أمر فحص في `check:web`.

## أعمال مقترحة لاحقًا — غير منفّذة
1. واجهة إدارة إصدارات حقيقية: سجل كل تعديل وتاريخ/محرر/استعادة إصدار قديم بضغطة، وحصص تخزين واضحة.
2. تحرير Word/Excel/PDF داخل التطبيق عبر محرر مستندات متكامل مع حفظ التغييرات، أو دمج آمن مع تطبيقات Android بواسطة Storage Access Framework. المشاركة الحالية **لا** توفر تحديثًا تلقائيًا للملف الأصلي بعد التحرير الخارجي.
3. معاينة أصلية للمستندات Office/PDF على Android باستعمال مكونات محلية موثوقة، دون رفع المستندات لخدمة خارجية دون إذن.
4. بحث داخل النصوص وPDF وWord عبر فهرس محلي/OCR، وليس بالاسم فقط.
5. عرض إحصاءات استهلاك التخزين وتنبيهات السعة وقوائم الملفات الكبيرة والمكررة، مع أدوات تدقيق سلامة النسخ الاحتياطية.
6. اختبار الأداء مع 1000 عنصر وسيناريو انقطاع الإنترنت وتعارض التحديثات على جهاز Android حقيقي.

## حدود النشر
لا تُدمج التغييرات في `main` ولا تُبنى نسخة APK أو تُنشر تغييرات Supabase من هذه المرحلة تلقائيًا.
