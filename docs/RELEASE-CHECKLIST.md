# قائمة فحص إصدار Android

## فحص آلي

- `npm ci`
- `npm run check:web`
- إنشاء Android: `npm run android:prebuild`
- بناء Release بالمفتاح الصحيح.
- فحص ZIP وManifest والأصول والتوقيع ومواءمة مكتبات 16KB بواسطة `tools/verify_release.py`.
- مقارنة بصمة الشهادة مع APK السابق.

## فحص على هاتف حقيقي

- تثبيت 4.2 فوق 3.2/4.0/4.1 من دون إزالة التطبيق.
- التأكد من بقاء الإعدادات والمستندات وقاعدة IndexedDB.
- تشغيل المسح الضوئي وصانع الهوية والكاميرا الأمامية والخلفية والفلاش.
- قراءة QR وEAN وCode128 بكاميرا الهاتف.
- اختبار الباج التعريفي وباج الروضة/المدرسة وكارت الدخول وWi‑Fi أمام/خلف.
- اختبار CR80 وA4 وPDF وPNG وJPG والطباعة على Epson L8050.
- اختبار OCR بالعربية والإنجليزية، والقص والتدوير والعودة للأصل.
- اختبار إنشاء حساب، تأكيد البريد، المزامنة بين جهازين، والتعارض مع الاحتفاظ بالنسختين.
- اختبار الوضع المحلي ورفض الأذونات وانقطاع الإنترنت وامتلاء التخزين.
- اختبار الثيم الداكن وRTL والأسماء الطويلة وتكبير خط الواجهة.

نجاح Build وحده لا يعد قبولًا نهائيًا؛ يجب توثيق نتائج الهاتف والطابعة.
