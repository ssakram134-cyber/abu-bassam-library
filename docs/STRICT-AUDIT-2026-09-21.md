# تدقيق التعديلات الصارمة — 2026-09-21

يُحدّث هذا الملف بعد CI وتجربة المصدر. لا تعني القائمة أدناه أن اختبار الهاتف تم.

- النماذج الخاصة بكل قسم فقط: يحتاج فحص CI.
- نماذج الروضة العشرة الحقيقية: يحتاج فحص CI + تجربة هاتف.
- عدم تداخل عناصر الباجات والكروت: يحتاج فحص المصدر + تجربة هاتف.
- القوائم القابلة للطي: يحتاج فحص المصدر + تجربة هاتف.
- الشهادات داخل الباركود والكروت: يحتاج فحص CI.
- إزالة الظروف من الباركود والكروت: يحتاج فحص CI.
- قسم «الأسئلة والظروف»: يحتاج فحص CI.
- نوع سؤال مستقل لكل سؤال: يحتاج فحص CI + تجربة لمس.
- علوم الثالث والرابع (سهل/متوسط/صعب/تسلسل): يحتاج فحص CI.
- الإسلامية (الحفظ/الحديث/التلاوة/العقائد والعبادات/المعاني/السيرة/الآداب): يحتاج فحص CI.
- أدوات الظرف: قفل/تحريك/حجم/دوران/حذف/نسخ/نص/صورة/تنسيق/تراجع/إعادة/صفحات/توقيع/دعاء/PDF/طباعة: يحتاج فحص CI + تجربة هاتف.
- مصالحة الجهاز الرئيسي وإزالة سجلات الأجهزة المكررة: يحتاج فحص SQL + تطبيق migration على Supabase + تسجيل دخول فعلي.
