# بناء APK من الهاتف، دون كمبيوتر ودون GitHub Actions

## المتطلبات والخطوات على الهاتف
1. افتح https://codemagic.io/ من متصفح الهاتف وسجّل دخولك أو أنشئ حساباً.
2. اختر **Add application** ثم **GitHub**، وأذِن لبرنامج Codemagic بالوصول إلى المستودع **ssakram134-cyber/abu-bassam-library** فقط (لا حاجة للسماح بكل المستودعات).
3. حدّد المستودع واختر **React Native** عند الحاجة.
4. اختر الفرع **build/manual-cloud-apk-20261013** عند فحص الملف `codemagic.yaml`.
5. شغّل workflow باسم `abu-bassam-manual-apk` **يدوياً** من لوحة Codemagic؛ لا يوجد مشغل تلقائي لهذه العملية.
6. في حال نجاح الاختبارات والبناء وفحص التوقيع، افتح **Artifacts** ونزّل ملف `.apk` مباشرة من الهاتف، ثم طابق بصمته مع `APK_SHA256.txt`.

## قواعد السلامة
- هذا المسار يبني **APK تجريبياً**؛ دون تزويد Codemagic بمفتاح التوقيع الإنتاجي الأصلي لا يعدّ نسخة تحديث صالحة لتطبيق مثبت بتوقيع آخر.
- لا تحذف النسخة الحالية ولا تزيل التطبيق الذي يحتوي أرشيفك/مستنداتك من أجل تثبيت نسخة اختبار؛ النسخ بتواقيع مختلفة لا يمكن تثبيتها كتحديث متوافق.
- يمنع إدخال مفاتيح Supabase السرية أو كلمة مرور Keystore داخل GitHub أو `codemagic.yaml`؛ إذا استُخدمت توضع في مخزن أسرار الخدمة.
- تشغيل `npm run check:web` إلزامي، ولا يسمح تجاوز فشل فحوص الأمان لمجرد استخراج ملف APK.
- تكامل GitHub بـCodemagic يحتاج قبول صلاحيات المستخدم، ولم يُربط الحساب أو يُشغّل البناء من هذه المحادثة.
- يحتاج التوقيع الإنتاجي إلى الـkeystore الأصلي؛ إنشاء مفتاح عشوائي جديد سيمنع تحديث النسخ القائمة إذا كانت موقعة بمفتاح سابق.
- هذه الملفات مُضافة إلى فرع منفصل يستند إلى كل الإصلاحات السابقة. لم يحدث بناء عبر GitHub Actions أو دمج إلى `main`.
